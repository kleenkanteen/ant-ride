The join and edit participant pages both own validation, defaults, and request glue, while ParticipantDetails leaks react-hook-form state and transport details to every caller.

Split route normalization from MapLibre rendering

The map module combines data shaping, color assignment, and imperative MapLibre calls in one effect; the page has to hand it raw event_data, so the interface is as wide as the implementation.

Problem

The map module combines data shaping, color assignment, and imperative MapLibre calls in one effect; the page has to hand it raw event_data, so the interface is as wide as the implementation.

Solution

Move route normalization and layer planning into an internal route-visualization module; leave CarpoolMap as a thin MapLibre adapter.
